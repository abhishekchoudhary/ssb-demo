The **Explore** menu has nested groups. The footer combines text, links, an image, icons, and an HTML note. The header stays visible while you read.

## Make it yours

Open the editor at the site's usual admin address. **Content** holds these posts and pages. **Media** holds their pictures and films. **Design** holds the small homepage, post, and site-wide additions. **Settings** holds the homepage choice, menu, footer, logo, and text.

All of these examples can be edited or removed through those controls. Nothing needs to be published to GitHub just to try an edit locally.
